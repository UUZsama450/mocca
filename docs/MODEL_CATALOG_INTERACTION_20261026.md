# 模型目录点击范围与轻量搜索（本地候选）

初始基线：GitHub v1.0.7 / `63de3759`。点击范围和搜索已随本地 5254 安装；5255 在此基础上补充短点击识别与触感反馈。存储、服务商配置持久化与已发布标签保持原状。

## 交互

“从列表添加”的整行 Button 改为右侧独立的 + / − Button。保留 44 × 44 点控件、VoiceOver 模型名与选择状态、原有添加/取消动画及分组/全选行为。名称、能力标签和主要留白不执行添加。

5255 只给此处按钮使用局部 UIKit 短点击识别器：松手时触摸时间必须小于 0.45 秒，移动超过 10 点即取消，另保留系统点击识别规则。普通点击不增加等待，停留后松开或继续滑动不切换、不震动。没有识别长按，也不拦截父级滚动。最初 SwiftUI 长按组合方案在“停住再滑”测试中阻止了滚动，已移除，未安装到手机。

每个已实例化的按钮增加一个 UIView、协调器和点击识别器；原 LazyVStack 保留。触摸期间只比较时间和坐标，没有定时器、滚动代理、逐帧观察、网络或存储操作。成功切换后调用现有 `performListItemHaptic()`，遵循列表点击与全局触感开关。VoiceOver 仍有明确的激活动作；本地触摸测试不等同于真实 VoiceOver 使用验收。

## 搜索

目录、默认模型选择与收藏结果使用同一匹配规则：不区分大小写、忽略名称中的标点/分隔符、空白分开的多个词全部命中，词序不限。例如 `gpt4o` 可匹配 `gpt-4o`，`sonnet claude` 可匹配 `claude-3-7-sonnet`。默认模型选择还支持服务商名和模型名的关键词组合。

不是语义搜索或拼写纠错；没有网络调用、后台任务、定时器、持久化索引或缓存。空搜索直接返回原列表，不归一化候选。每次过滤只预处理一次查询；常见 ASCII 模型 ID 使用轻量 UTF-8 匹配，中文等名称保留 Unicode 字母/数字。

## 本地验证

- 18 个匹配行为用例通过：空输入、大小写、分隔符、多词/倒序、服务商+模型、中文、数字版本、标点查询及不匹配。
- 5254 的 5 个独立 XCUITest 用例通过：名称/正文侧点击不添加、半屏 sheet 中 + / − 各切换一次、从名称区域滚动不添加、从 + 开始拖动取消按钮动作、搜索后点 + 添加。5255 增加“停住再滑”和“停住松开/轻微移动再松开”，并检查成功切换的触感调用次数。
- UI 宿主抽取真实行、切换与过滤方法；模型数据、图标及能力标签为合成 fixture，不运行 App 启动服务、不接触聊天或真实服务商。它验证触摸路由，不代表完整设置页或真机手感验收。
- Mac 优化构建样本（每组 10 次）：200 项约 0.25–0.29 ms，1,000 项约 1.0–1.3 ms，10,000 项约 10–13.6 ms。空查询跳过匹配。仅测匹配，不包含列表排版，也不是 iPhone 帧率或延迟保证。

5255 最终目录界面测试 10 项通过，额外覆盖 320 点宽度下中英文“反选”、筛选范围及名称/型号两行排版。名称和型号分别最多两行，短内容不预留空白；极长型号中间省略，保留首尾。没有文字滚动动画或额外测量循环。
