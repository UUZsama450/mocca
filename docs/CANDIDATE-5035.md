# 5035：键盘与弹层的滚动目标交接

基线：5034 `3ad697d`，独立候选 `codex/keyboard-modal-handoff-5035`。

## 问题与改动

键盘打开时进入工具或模型选择，5034 把 SwiftUI 几何快照的底部距离加到实时 UIKit offset 上。原生 inset 布局若已先行调整 offset，这会重复计算位移。此前两条模拟器记录均出现约 302 点错误目标，随后完成任务无动画贴底。

5035 在几何快照生成时，用该快照自己的 offset 与距离计算绝对底部目标，并把它作为载荷传到现有 UIKit 动画。保持原来的六个几何观察字段，避免新增回调。

当 `.bottom` 仍由原生布局持有、没有待完成的自定义键盘任务，且实际 offset 已在该目标 2 点以内时，直接保留现有定位和动画。不能先释放 `.bottom` 再重复写同一个目标：受控对照中，即使目标修正，释放后仍会发生 302 点回写。若自定义动画仍持有位置或有待完成任务，继续原来的重定向／合并流程。

诊断日志额外显示命令发出时的原生 offset 与原生底部，并记录复用原生定位的分支，仅在现有诊断开关开启时求值。没有新增动画任务、计时器或逐帧回调。

没有改变动画时长／曲线、完成任务或取消条件。历史阅读、手指接管、导航、发送、流式跟随、折叠归属、iOS 17 兼容路径以及工具／模型入口的焦点策略保留。

产品差异为 `Mocca/RootView.swift` 的目标计算与诊断载荷，以及主 App／扩展构建号；没有修改数据存储或迁移。5034 候选与既有安装产物保留作为回退来源。
