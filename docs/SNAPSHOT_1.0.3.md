# 1.0.3 (5194)

[更新说明 / What’s new](../CHANGELOG.md) · [Installation](INSTALLATION.md) · [Source variant](SOURCE_VARIANT_1.0.3.json)

This release adds model brand icons and per-member model selection in group chats, improves long-text selection, streaming display and code highlighting, and refines sending, image loading and the chat interface.

## Source and validation

- Based on the installed **1.0.2 (5193)** development source. This release does not make a new physical-device performance claim.
- The portable iPhone Release build passed with all **148 frozen product inputs unchanged**. The separate App Store archive passed with all **156 frozen product inputs unchanged**.
- Model-name and Codable checks passed **24 assertions**. Sponsorship build and disabled-operation checks passed **5 cases**.
- Both app and extension are **1.0.3 (5194)**. The portable binary is arm64, contains the expected 250 code-highlighting resources, and excludes screenshot fixtures and diagnostic markers.
- Established portable signing placeholders, sponsorship disabled by default, neutral examples, reviewed assets and repository policies remain in place. The manifest records source differences and hashes.
- README screenshots show current product views with fictional conversations in an isolated simulator. No personal chats or API credentials are used.

## Distribution

The [GitHub preview IPA](https://github.com/UUZsama450/mocca/releases/tag/v1.0.3) requires your own signing. It contains no signing certificate or provisioning profile. Signing and installation on a third-party account have not been verified. See the installation guide and the release SHA-256 checksums.

The App Store build is distributed separately and is set to **manual release after review**. The GitHub preview does not mean the App Store update is live. The [App Store page](https://apps.apple.com/us/app/mocca-ai-chat/id6807043522) always shows the currently available store version.
