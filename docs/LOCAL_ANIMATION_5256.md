# 本地 1.0.7（5256）上抬动画优化

基于已安装的 5255。App Store 上传按用户要求暂停；此轮只做本地优化、验证和同 Bundle ID 手机更新。

## 改动范围

- `NativeChatTranscript` 为行数组保留一个快照标识。只改变输入框/底部几何的副本复用标识；赋值、下标修改、增删或重排数组均产生新标识。控制器记录实际安装的快照，避免将尚未应用的数据误认为已安装。
- 同一快照的几何更新跳过重复 ID 映射、集合构造、revision 比较和字典重建。结构、revision、publication、真实测量、宽度/间距等变化仍走原来的更新路径；没有新增计时器、观察器或后台任务。
- `ComposerView.swift`、`ComposerNativeTextInput.swift`、`RootView.swift`、`MessageMarkdownView.swift` 与 5255 完全一致。保留 0.18 秒曲线、中文输入弹簧、底部跟随、历史位置和文本绘制方式。
- 仅全新安装且没有偏好记录时，将输入框伸缩动画默认设为关闭并保存。现有显式开/关、旧存档缺失字段和旧安装缺失偏好保持原行为。聊天上抬动画仍独立运行。复用启动时已有的新安装判定。
- 服务商类型标签使用图片原色；OpenAI 浅色为黑、深色为白。其他控件继续继承系统 tint。新增深色 SVG 只改变填充色，图形路径不变。

聊天持久化与备份实现没有改动：`ConversationStore.swift` 和 `BackupService.swift` 与 5255 相同。`SecureStore.swift` 的改动仅为上述偏好默认值和首次保存。

## 已验证范围

- 实际控制器回归：14 组场景、510 项检查通过。包含快照复制及各类数组变更、publication 刷新、延迟采用快照、增删/重排/修订、重复 ID、会话隔离、空列表和拆卸。
- 实际完整 App 的合成数据 UI：短聊天、500 条长聊天底部和历史阅读三项测试通过，覆盖输入框增高/缩短及阅读位置。截图核对未发现异常空白或跳位。
- 六项默认值测试通过：新安装首次/再次启动、旧安装无记录、显式开/关、旧存档缺失字段、偏好编码往返，以及现有损坏记录不被覆盖。初版测试发现通用偏好保存依赖 Keychain；最终改为在密钥载入前直接保存不含凭据的新建默认值，消除该依赖。
- 最终偏好、独立上抬动画与存储回归共 30 项通过。输入框动画关闭时仍检查聊天上抬、历史锚点、短聊天和中文组合输入；存储用例只操作合成临时数据库。
- 弹窗、消息编辑与图标七项 UI 测试通过；核对浅/深色 Picker 和展开菜单四张截图，OpenAI 标志分别显示黑/白，其他彩色标志保留原色。
- 动画组件对比使用生产控制器/原生输入代码，覆盖短/长列表、360 条窗口、历史阅读和中文组合输入；具体最终对比记录位于 `work/phone-5256/verification/`。

编译完成后按旧版/新版、新版/旧版顺序执行四轮对比，全部通过原有布局检查。每次控制器更新的模拟器墙钟耗时如下（毫秒，两轮范围；不是帧耗时）：

| 场景 | 5255 | 5256 |
| --- | --- | --- |
| 4 条短列表 | 0.471–0.519 | 0.455–0.517 |
| 120 条底部跟随 | 1.605–1.665 | 1.437–1.498 |
| 360 条底部跟随 | 2.032–2.236 | 1.636–1.795 |
| 120 条历史阅读 | 0.340–0.372 | 0.227–0.248 |

六种场景的动画结束位置、文字锚点、内容高度和底部间距对比一致。旧版第二轮中文场景收键盘后多测量了四条新露出的行（每条从 240 点预估值变为 48 点实测值），因此原始最终 offset 差 768 点。原测试逐行验证了准确的前缀位移及底部跟随；保留原始差值，按已验证的测量修正对比后相同。新版两轮未出现该差值。没有为了匹配数字而禁止必要测量，或改动产品滚动逻辑。独立对比脚本为 `CandidateTests/compare_composer_snapshot_runs.py`。

测试宿主均使用专用模拟器及合成数据。模拟器的控制器耗时不是整帧 CPU/GPU 或真机 ProMotion 帧率；正常可见单元仍可能执行必要的尺寸测量，不能表述为“动画完全不排版”。真机流畅度和视觉感受需在安装后由用户确认。

安装包输入哈希、签名核验、5255 回滚包和部署回读记录保存在 `work/phone-5256/`。安装状态以 `deployment.json` 为准。

最终 Release 签名、主 App/扩展权限、arm64、dSYM、源文件哈希和测试代码排除核验通过。已在指定 iPhone 17 Pro 上从 5255 同 Bundle ID 原位更新至 1.0.7（5256），版本回读与正常启动通过。未卸载、清空或访问聊天容器；5255 回滚包保留。真机帧率和用户手感尚未验收，未上传 App Store 或推送 GitHub。
