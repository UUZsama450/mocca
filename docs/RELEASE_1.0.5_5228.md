# Mocca 1.0.5 (5228)

Consecutive sending now uses a saved wait of 3–15 seconds in single chats, with 7 seconds preserved for existing preferences. Each send restarts one cancellable wait; changing the preference applies to subsequent sends. Disabling the feature preserves its selected duration and existing pending-message behavior. The settings slider updates locally while dragging and saves the completed adjustment.

This version includes paragraph-based replies for single and group chats, optional custom bubble spacing, composer typography and resizing improvements, and the off-bottom send repair. Standard settings row labels use regular body weight. Both drawer disclosure arrows point down when collapsed, rotate up when expanded, and use the same 0.26-second ease-out animation.

The portable project retains configurable signing, disabled-by-default sponsorship, neutral examples and reviewed artwork. Its unsigned IPA requires the recipient's own signing; the developer-signed phone build is a separate artifact. No App Store submission is part of this release.

Validation results and source identifiers are recorded in the release build manifest. Simulator checks do not establish physical-device frame rate, energy consumption or thermal behavior.
