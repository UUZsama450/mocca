# 侧边栏已接管拖动后的斜向松手修复与 5257 手机安装

基于已安装 1.0.7（5256）的 `970ef4b7`，修复提交为 `66187a76`。最初按用户要求只本地修改和验证；2026-10-26 用户重新授权手机安装，现已安装 1.0.7（5257）。App Store 上传仍暂停。

## 问题与改动

起手已有 `drawerGestureLocked` 方向归属，但 `onEnded` 又检查横向距离是否大于纵向的 1.75 倍。手指先横滑、侧边栏已跟手，随后向上或向下拐时，这次检查可能撤销开合，退回原来的状态。

仅修改 `RootView.swift` 的松手分支：去掉第二次横纵比例检查及不再使用的 `dy`。保留已接管状态、有效进度和原有 18 点净横向距离检查。实际开合继续使用原来的进度、横向预测与距离阈值，因此短拖、反向拖回、快速甩动仍按原规则决定落点。

开始阶段的 18 点/1.75 倍判断、竖向拒绝、文字选择/横向滚动优先级、侧边栏内控件防误触、动画中接管、取消及清理均不改动。
