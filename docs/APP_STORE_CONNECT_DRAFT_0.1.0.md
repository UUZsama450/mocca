### 描述

Mocca 是一款原生、可自定义的 AI 聊天客户端。你可以连接自己选择的兼容模型服务，在一个简洁的界面中管理对话、助手与常用工具。

主要功能：

• 自行配置兼容服务商、API 地址、密钥与模型
• 创建单人对话和多助手群聊
• 支持图片、文件、Markdown、代码与数学内容
• 可选的网页搜索、语音播放和 MCP 工具
• 自定义助手提示词、近期记忆与世界书
• 支持后台生成与实时活动状态
• 对话主要保存在设备本地，并可导入、导出和备份

Mocca 不提供自有模型账户，也不会代替第三方模型服务商处理其计费。调用模型、搜索、语音或工具服务时，相关内容会发送给你选择的服务商，并受该服务商的条款与隐私政策约束。

你也可以通过可选的“投喂”支持开发。投喂不解锁聊天功能，不会自动续费；首次购买某个档位会留下对应的纪念装扮。

Mocca 是独立、非官方项目，与 Kelivo 原作者及各模型、搜索服务商不存在隶属或背书关系。Kelivo 名称仅在旧备份兼容和来源说明中使用。

### Review Notes 草稿

Mocca 没有自有账号系统。首次启动后，请进入“设置 → 服务商”，使用本页提供的审核专用配置添加模型服务，然后新建对话并发送消息。

主要审核路径：

1. 新建普通对话，发送文本并查看流式回复。
2. 从附件按钮选择图片或文件；照片和相机权限只会在用户主动选择对应功能时请求。
3. 在助手设置中按需启用网页搜索、位置、日历或提醒事项工具；权限只在实际执行相关功能时请求。
4. 发出消息后离开 App，可查看后台生成与 Live Activity；是否持续执行受 iOS 系统调度限制。
5. “设置 → 关于”中可查看使用文档、隐私政策、许可证与来源说明。

“投喂 Mocca”包含三个可重复购买的 Consumable 商品。购买是自愿支持，不解锁聊天或其他功能，不会自动续费。每个档位首次购买会解锁该档位对应的纯装饰纪念物；任意首次投喂还会留下共同的水滴纪念。再次购买同一档位不会增加新的功能或重复装扮。消耗型赞助不提供系统“恢复购买”入口，也不承诺换机或重装后恢复。

Mocca 是独立、非官方衍生项目。Kelivo 名称只用于旧备份兼容和许可证/来源说明，不表示原作者或任何第三方服务商的认可。

## App Privacy 填写边界

不能只照抄 `PrivacyInfo.xcprivacy`。App Store Privacy 需要同时考虑 App 自身和集成/调用的第三方数据实践。

- 仅在设备本地处理、从未离开设备的数据通常不算“收集”。
- 用户主动发送给模型服务商的文本、图片、文件和音频，需按最终服务商是否保存、用途及是否与身份关联如实填写。
- 网页搜索、语音、MCP 和自定义 API 地址同理；不能在未确认服务商保留策略时统一填写“不收集”。
- Mocca 当前未集成广告或行为跟踪 SDK，Privacy Manifest 中 Tracking 为 false；仍需用最终 Archive Privacy Report 复核。
