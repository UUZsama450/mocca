# 4982：旧聊天归属隔离

候选：`work/candidates/mocca-orphan-chat-ownership-4982-a`

基线：手机测试包 `com.uuzsama450.mocca.migration`，`0.1.0 (4982)`，对应源码 `71fbf65`。本候选保持原项目版本号，尚未部署；候选目录里的 4982 不代表修复已经在手机上。

## 问题与实际证据

2026-09-09 只读检查手机：新助手有独立的新 UUID、没有导入标记、没有归属于它的聊天。主存档内另有 7 个 `old_kelivo` 聊天、335 条消息；这些聊天的 `assistantID` 为空，迁移元数据保留了同一个已不在助手表中的旧助手 ID。

原侧边栏把 `assistantID == nil` 当作匹配所有助手。冷启动、恢复选择和近期记忆源筛选也有相同的隐式归属规则。导入器在旧助手不在设置导出内时，则会把原本存在的归属 ID 转成 nil。

原始手机资料仅用于只读诊断，临时副本已删除。测试夹具均为合成资料，不包含用户聊天。

## 改动

- `Conversation.belongsToSingleChatAssistant` 统一明确归属的单聊判断；未知归属不再跟随当前助手。
- 侧边栏、启动选中、恢复选中和近期记忆源筛选使用同一规则。
- 无可选单聊时创建当前助手的空草稿，保留已加载的所有聊天与消息。只有本次启动新建的未保存空草稿会补上当前助手归属，已有无主记录不被认领。
- Kelivo 导入用原有稳定 UUID 算法保留缺失助手的身份引用，不创建助手档案。单聊归属、群聊成员、消息作者和反应作者使用一致的映射，避免缺失成员使群聊变成单聊。
- 不修改原有无主聊天记录、不删除消息、不调整人设或工具续答提示。
