# 表格公共文字样式复用候选

## 问题与最终改动

5009 的表格会为每个单元格分别设置字体、行距、无限行数、文字颜色和链接色。首次创建长表格时，这些相同的设置随格子数量重复构造。旧的 4998 真机日志能定位到内容准备和首次关闭期间存在差异，但没有成功导出的 CPU 调用栈，不能证明公共样式就是手机上的主要热点。

本候选将相同的设置移至原有 Grid，让格子继承；表头 GridRow 单独使用原来的半粗字体。保留原 Grid、自然高度、单元格宽度/内边距/背景、Markdown 解析、链接、每格菜单和横向滚动。产品只修改 `Mocca/MessageMarkdownView.swift` 中的表格样式设置，没有新增缓存、任务、计时器、状态发布或手势监听。

试验过另一种固定列宽 Layout；修正 RTL 后几何一致，但电脑端中位耗时只减少 1.1%～3.8%，不足以支持新增布局实现，因此已撤回。该实验仅保存在 `work/verification/table-fixed-columns/`，不在最终产品代码中。

## 基线与回退

- 基线是已安装到 17 Pro 的 1.0 (5009)，来源为相邻 `mocca-chat-thumbnail-background-a`。
- 创建候选前，重新验证签名构建记录中的 252 项输入，全部匹配；候选从 HEAD `7ec3d71810909fb5aed97c257a576a1e3fefc9c8` 加实际未提交内容创建。
- 分支为 `codex/table-shared-style`。原有工程、Attachments、RootView、ChatContentMutation 差异属于 5009；应相对冻结基线审查，不能把它们当作此次改动。
- 原 5009 源码和签名安装产物保留，并在此次安装前复核签名和二进制哈希。电脑端无签名验证曾沿用 5009 工程号；用户随后授权安装，正式为本候选分配 5010，四处工程构建号同步更新。

## 电脑端验证

`check_table_shared_style.py` 从实际 5009 和候选文件提取表格，运行相同的 macOS SwiftUI 宿主。平台桥接为 NSFont/NSColor；合成单元格使用相同的原生 AttributedString Markdown 解析，替代未改动的 App 解析兼容层；侧栏横向手势探针用透明视图替身。表格和 Grid 结构直接来自生产源码，不重写被比较的布局。

- 17 组原版/候选对照，5,870 个 frame 坐标比较，无差异。涵盖中英文、链接/粗体/代码、换行和组合字符、内容替换、增减行、字体/字号/行距变化、RTL、表头单独显示、单列、32 行 5 列及有限高度父容器。Mac 对 Dynamic Type 的结果不能扩展为 iOS 动态字体验收。
- 保持同一宿主更新内容，检查文字没有越出单元格、表格后的正文没有重叠；这些更新同时验证了共享样式随输入变化。
- 初始表格、替换末行长文字、RTL 三组 Grid/单元格渲染图均与 5009 逐字节一致；已经目视复核字体、换行、链接颜色及边框。此项不覆盖平台滚动容器或弹出的系统菜单。
- 性能宿主编译时去掉几何探针。原版与候选交替顺序，各尺寸 6 轮；每次清空两侧共同的测试文本缓存，排除首轮后取 5 个样本中位数。

| 合成表格 | 原版中位数 | 候选中位数 | 变化 |
|---|---:|---:|---:|
| 16 行 × 5 列 | 145.365 ms | 140.474 ms | -3.4% |
| 64 行 × 5 列 | 515.636 ms | 488.973 ms | -5.2% |
| 160 行 × 5 列 | 1329.487 ms | 1269.496 ms | -4.5% |

这些数字是电脑上合成内容的创建/初始布局耗时，包含平台宿主开销，样本分布有重叠；不能当作 iPhone 提速幅度、真实点击延迟或侧栏 FPS。它支持保留这项较小的重复工作简化，不支持宣称长表格问题已解决。

原始结果位于 `work/verification/table-shared-style/host/`。离屏 NSHostingView 截图可能为空，ImageRenderer 也不绘制此环境下的平台 ScrollView；视觉对照单独渲染原有 Grid/单元格子树。完整几何对照仍包含原横向、纵向滚动容器。
