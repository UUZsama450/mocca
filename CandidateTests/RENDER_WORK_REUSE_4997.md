## 范围

用户在全范围审计后授权实施推荐的第一小批。本轮只整理工具卡片 JSON、回答版本控件查询、助手图片缓存命中顺序，不实施审计报告中的其他候选。

- 工具卡片：在同次显示计算中复用解析结果，组摘要一次计算并将结果传给展开的子行；参数仍仅在对应工具文案需要时解析。保留原文案、错误判断、无障碍描述、参数优先级和展开内容。
- 回答版本控件：显示时复用版本列表及索引，点击时仍从当前模型读取；使用所属 conversationID 查询并校验消息仍存在，沿用原排序。按钮保留原来的 selectedIndex 捕获语义及点击时边界检查。
- 助手图片：reference 和文件名校验后先查现有内存缓存，未命中时沿用原文件读取及缓存写入流程。

没有新增常驻缓存、观察状态、定时器或滚动协调器；保留 4996 的高亮、折叠、流式节拍及定位流程。

图片读取有一个明确的边界变化：目录准备失败但内存已有有效缓存图时，现在可直接返回缓存图；旧实现会在查缓存前返回 nil。文件名校验及缓存未命中行为保持原样，没有扩大到图片清理或大图预览生命周期。

工具结果保留原有两类规则：错误状态读取原始 JSON 对象，预览允许标量 JSON 并去除外层空白。普通有效 JSON 共用一次解析；当原始解析失败、而去掉较宽的 Unicode 空白后可以用于预览时，保留兼容解析。这里不是永久缓存，也没有新失效策略。
